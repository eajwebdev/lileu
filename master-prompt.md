# LIL’EU OFFICIAL BRANDING + RESELLER RECEIPT DESIGN UPDATE

Use the actual Lil’Eu logo already supplied by the owner and stored inside the project's:

public/

folder.

The logo features a dessert-inspired visual identity with:

* Chocolate brown
* Soft blush pink
* Warm cream
* Vanilla/off-white
* Small cherry red accents
* Golden/caramel food accents

The entire website and management system must visually match this identity.

# 10. TYPOGRAPHY

Use a premium readable font for the application.

For the public landing page, headings may have slightly more personality.

However:

Do not use overly decorative fonts for tables, POS or management interfaces.

Recommended approach:

Brand/marketing headings:
Elegant soft serif or rounded display font

System UI:
Clean modern sans-serif

Receipt:
Readable serif/sans-serif combination matching the sample design

Maintain consistent typography hierarchy.

# 11. RESELLER RECEIPT DESIGN

The RESELLER RECEIPT is especially important.

Create a professional printable reseller receipt inspired closely by the owner's supplied reference.

The visual structure should follow this composition:

CHOCOLATE HEADER

↓

CREAM RECEIPT BODY

↓

CUSTOMER / ORDER INFORMATION

↓

ORDER ITEM TABLE

↓

DARK CHOCOLATE TOTAL BAR

↓

PAYMENT STATUS STAMP

↓

FOOTER MESSAGE

The receipt must look intentionally designed for Lil’Eu and not like Laravel's default PDF output.

---

# 12. RECEIPT HEADER

Use a full-width dark chocolate header.

Background:

#3B2A22

Text:

Warm cream / off-white

Display:

Lil’Eu Cafe Est. 2026

or the configurable official business name.

Under it:

Do NOT hard-code the year.

# 18. PAYMENT STATUS STAMP

Create a visually styled payment stamp similar to the reference.

For fully settled orders:

Use green outline/text.

For 50% downpayment only:

or:

Do NOT use only:

PAID

when the reseller still owes a balance.

This prevents accounting and customer misunderstandings.

# 28. RECEIPT NUMBER VS ORDER NUMBER

Keep these separate.

Example:

Reseller Order:

RE-2026-000012

Payment Receipt:

LE-20260902-001301

A reseller order can therefore have multiple payment receipts.

Example:

Order:
RE-2026-000012

Downpayment Receipt:
LE-20260902-001301

Balance Receipt:
LE-20260905-001842

This is required because the 50% and remaining 50% may be paid separately.

# 36. DESIGN REFERENCE PRIORITY

The supplied Lil’Eu logo and receipt images are the PRIMARY visual references for this application.

When implementing the design:

1. Inspect the actual logo from public/
2. Match the warm chocolate/pink/cream identity
3. Recreate the overall receipt composition from the supplied receipt reference
4. Adapt it professionally for dynamic system data
5. Maintain readability and responsive behavior

Do not copy random SaaS dashboard palettes instead.
